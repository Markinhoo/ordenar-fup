# Ordenar FUP

Aplicación estática para ordenar RFC y folios dentro de una plantilla Excel y repartir los registros entre personas con colores. El archivo se procesa en el navegador.

## Estructura

- `dist/`: sitio listo para publicar, sin compilación.
- `vercel.json`: indica a Vercel que publique `dist/`.

Los cambios en la rama `main` del repositorio `Markinhoo/ordenar-fup` se pueden usar para despliegues automáticos una vez conectada esa rama al proyecto `ordenar-fup` en Vercel.
